# 🎬 CineVerse

A modern and responsive movie website built with **HTML5, CSS3, and Vanilla JavaScript**.

### ✨ Features
- 🎥 Trending & popular movies
- 🔍 Movie search
- ⭐ Ratings & release years
- 📄 Movie details
- 📱 Responsive design
- 🎞️ Trailer links

### 🛠️ Tech Stack
**HTML5 | CSS3 | Vanilla JavaScript**
